# IDGAF Onboarding Flow

Build the IDGAF App — Registration & Onboarding Flow

Create a modern, polished, professional health and nutrition app called IDGAF.

The attached hand-drawn wireframe represents the intended structure and order of the screens. Treat it as the functional reference, but significantly improve the visual design, spacing, typography, usability, and interaction design.

The app should feel like a modern AI-powered nutrition companion, not a generic fitness dashboard.

Overall Design Direction

Use a clean, minimal, premium UI.

Visual style

Modern health-tech aesthetic

Minimalist layouts

Rounded cards and buttons

Generous whitespace

Strong typography hierarchy

Subtle shadows

Smooth transitions between onboarding screens

Professional but slightly playful personality

Avoid an overly clinical hospital/medical appearance

Avoid excessive gradients, excessive illustrations, or clutter

Suggested color palette

Use a primarily light interface:

Off-white / very light background

Dark charcoal text

Fresh green as the primary accent

Slightly darker green for important actions

Soft gray for secondary text and borders

The design should be easy to adapt to an IDGAF mascot later.

Typography

Use a modern sans-serif font such as:

Inter

Plus Jakarta Sans

Manrope

Use bold typography for headings and clear, readable body text.

ONBOARDING BEHAVIOR

The onboarding should behave like a real production application.

Navigation

Continue moves forward one screen.

Back returns to the previous screen.

Data entered on previous screens must remain populated when going back.

Users should not lose information when navigating backward.

Do not allow Continue when required information is missing.

Show clear validation messages.

After completing Registration Page 8, save the complete onboarding profile.

Progress

Show a subtle progress indicator on Registration Pages 1–8.

Example:

● ● ● ○ ○ ○ ○ ○

or:

Step 3 of 8

The progress indicator should update automatically.

Animations

Use subtle transitions between screens:

Fade

Slide

Small scale transition

Animations should be fast and professional.

Do not over-animate the interface.

RESPONSIVE DESIGN

The application must work properly on:

Desktop

Laptop

Tablet

Mobile

On desktop, use a centered onboarding container with a comfortable maximum width.

On mobile:

Inputs should occupy the available width.

Buttons should be easy to tap.

Cards should stack vertically.

Typography should scale appropriately.

The progress indicator should remain visible.

Do not simply shrink the desktop UI for mobile.

IMPORTANT UX PRINCIPLES

The registration should NOT feel like filling out a government form.

Each screen should ask one clear question or one logical group of questions.

Use conversational headings.

For example:

Instead of:

"Select Primary Objective"

use:

"What are you trying to achieve?"

Instead of:

"Select Physical Activity Level"

use:

"How active are you?"

Instead of:

"Enter Number of Meals Per Day"

use:

"How many meals do you usually eat?"

The experience should feel like IDGAF is having a conversation with the user.

IDGAF BRAND PERSONALITY

The name IDGAF should influence the copy and personality, but the app must still feel trustworthy and professional.

Use occasional short, confident copy such as:

"No crash diets."

"No nonsense."

"Eat smarter."

"Let's get serious."

"Your food. Your goals."

"We work with your lifestyle, not against it."

Do not make every screen sarcastic or use profanity excessively.

The core product should feel credible enough that users would trust it with their nutrition data.
